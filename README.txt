GITHUB PAGES-КЕ ЖАРИЯЛАУ

1. ZIP архивін компьютерде ашыңыз.
2. Архивтің ІШІНДЕГІ барлық файлдар мен қалталарды репозиторийдің түбіріне жүктеңіз. ZIP файлының өзін жүктемеңіз. index.html түбірде тұруы керек.
3. GitHub → Settings → Pages → Deploy from a branch → main → /(root) → Save.
4. Жариялау аяқталған соң Pages бөліміндегі сайт сілтемесін ашыңыз.

БАСТЫ БЕТ: index.html
ТӘРБИЕ: tarbie.html — 11 сынып, 330 сабақ; іздеу, таңдаулы, тапсырмалар, кері байланыс. Кері байланыс ағымдағы браузер сессиясында жиналады; TXT ретінде экспорттаңыз. Серверге жіберілмейді.
ҚАУІПСІЗДІК: kauipsizdik.html — 11 сынып, 124 сабақ; мәтіндер жүктелген PDF-тен қалпына келтірілді. PDF-тегі түпнұсқаға әр сабақта сілтеме бар.
ҚҰҚЫҚТЫҚ БАЗА: normativ.html — 3 топ, 56 жеке құжат беті. Сыртқы сілтемелер бастапқы жинақтан сақталды, олардың қолданыстағы мәртебесі тексерілмеген.

Интернетсіз: жергілікті HTML беттері, тәрбие тапсырмалары және PDF ашылады. Сыртқы құжаттар мен бейнелерге интернет керек.
Дизайн, навигация және материалдар бастапқы архив негізінде біріктірілді.
